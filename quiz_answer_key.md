# 12-question quiz — answer key
1. 1NF — atomic values and no repeating groups.
2. 2NF — removes partial dependencies on a subset of a candidate key.
3. 3NF — addresses transitive dependencies of non-key attributes.
4. HAVING — filters groups after aggregation.
5. INNER JOIN — returns matching rows.
6. COMMIT — makes transaction changes permanent.
7. B-tree — common ordered index structure.
8. Atomicity — all-or-nothing transaction behavior.
9. PRIMARY KEY — uniquely identifies each row.
10. COUNT() — counts rows or non-NULL expression values.
11. Query execution strategy — EXPLAIN QUERY PLAN output.
12. Referential integrity — references must point to valid parent rows.
